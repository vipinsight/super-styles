# Super Styles - Write Custom Styles and Scripts

Write and save custom styles and scripts for any websites in real-time.  
All the styles and scripts are saved automatically so that you don't lose any custom styling.
Super Styles is super light-weight & fast solution for custom styling and writing scripts.  

## Install

[Get Super Styles from the Microsoft Edge Add-ons store](https://microsoftedge.microsoft.com/addons/detail/lgcjpmgldoadgddlhigdadahfdecchcp).

## Notes

- Styles are saved per website (hostname) in the browser's extension storage and applied automatically when you visit that website.
- Your JavaScript runs in the page as a `<script>` element, so websites with a strict Content Security Policy may block it.
- Updating from version 1.0 moves your earlier styles over automatically.
